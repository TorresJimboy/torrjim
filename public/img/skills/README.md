# Skill icons

- `csharp.svg`, `aspnet-core.svg`, `swagger.svg`, `aws-lightsail.svg`, `vscode.svg`, and `rider.svg` use the C#, .NET Core, Swagger, AWS, Visual Studio Code, and JetBrains Rider logos from [Devicon](https://github.com/devicons/devicon) (MIT). AWS branding represents the Lightsail skill.
- `maplibre.svg`, `leaflet.svg`, `phpmyadmin.svg`, `google-play-console.svg`, and `app-store-connect.svg` are from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0), colored for the portfolio. Google Play and App Store branding represent their respective publishing consoles.
- `razor-pages.svg`, `dotnet-maui.svg`, `xaml.svg`, `rest-api.svg`, and `dapper.svg` are locally drawn illustrative icons, not official product logos.

All icons are stored locally so the new skill cards do not require extra image requests to an external CDN.
